# Workspace contents

This repository contains the HUMM project from the local `ghufgkdhgj` workspace.

| Local workspace location | Repository location |
| --- | --- |
| `mouthband/` app source, assets, tests, scripts, iOS and Android projects | Repository root |
| `web/` website source, assets and design documentation | `web/` (paths adapted for this repository layout) |
| `HUMM-App-Store-2026-10-05/` existing release deliverables | `HUMM-App-Store-2026-10-05/` |

The submission guide is also available in `docs/HUMM-App-Store-Submission.html`.
The dated ZIP is the existing October 5 source-project snapshot, not a signed App Store upload or a snapshot of subsequent website changes. Use the repository source for current development.

Generated Xcode output in `ios-build/`, Gradle caches and machine-specific configuration in `gradle-home/`, browser QA profiles in `.mb-e2e-tmp/`, installed dependencies, generated build output and macOS metadata are kept locally and are not versioned. Follow the app and website README instructions to install dependencies and rebuild.
