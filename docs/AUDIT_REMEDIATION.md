## What changed

**Paid features and billing.** Production ignores developer/tester grants and unsigned ownership flags. Only the configured product with verified RevenueCat CustomerInfo grants ownership. Initialization, listeners, purchases and restoration use the same evaluator, with unverified old-cache migration and foreground/export refresh. The paywall uses the exact configured Lifetime product and actual localized price; unavailable, pending, failed and unverified results are distinct. Selected Pro sounds and paid Tracks/Fix/Effect usage preserve provenance through import/redo/inheritance and entitlement changes. Tracks Undo restores the musical content before its lock, and further edits lock again. Export checks run before/after rendering and again before releasing cached video.

**Songs and microphone.** Project-scoped Undo cannot overwrite a different song. IndexedDB transactions update record/index/trash together, boot repairs orphan indexes, and serialized snapshot saves expose persistent retryable failures. Explicit save/switch waits for persistence. Microphone opening is single-flight; stale permission results, navigation, setup errors, background and cancellation close streams. Record/Redo/import share the documented 60-second free and 180-second paid limit. Import commit is tied to the originating project.

**Audio, import and export.** iOS uses a bounded native reader and system picker; long input is decoded only up to the allowed cap. DSP workers have cancellation/deadlines and no heavy main-thread fallback; the production classic worker supports the older WebKit path. Only the selected arrangement is prepared, with cache and active-buffer budgets and bounded render batches. Video handles constructor/start errors, cancellation, background, stalled clocks and size/deadline limits, while close releases preview Blob URLs. Share discloses the original recording and lets the user choose band-only video. Native temporary sharing uses chunked writes, secure random names, one-day expiry and a 128 MiB budget.

**Appearance and accessibility.** System/Light/Dark preference is persistent and follows system changes. Warm paper `#F6F4EF` and ink `#111111` reverse in dark mode; orange `#F0443A` stays unchanged. Native launch/status/WKWebView appearance follows the theme. Existing artwork and layout are preserved. Grids expose labeled buttons, state and keyboard navigation. Nested sheets contain/restore focus and hide the background, including an older-iOS fallback. The 16-part rail scrolls; portrait iPad windows use the existing rotated-editor fallback. Zoom and native Dynamic Type scaling are enabled. Dense cell target sizes still require accessible-touch acceptance; see QA-12.

**Privacy, dependencies and releases.** First release offers no account creation or Apple sign-in. Legacy identity removal propagates Keychain errors. Privacy and listing copy accurately describe anonymous purchase reporting, local audio, sharing, backups and lazy retention. Purchase History includes App Functionality and Analytics in the manifest. A scoped dependency patch clears the known uuid advisory. Release scripts validate effective owner configuration, archive without automatic upload, and require explicit upload intent. Manual Xcode Archive also checks for validated release assets.

## Remaining technical limits and product decisions

- **QA-12 accessibility:** grid cells remain small to preserve the existing editor. Zoom, keyboard semantics and native text scaling improve access; actual largest text/VoiceOver/touch acceptance is outstanding. Add a magnified editor if those alternatives fail usability on small devices.
- **CORE-02 browser import:** encoded-size/duration checks reduce exposure, but accepted input is still decoded fully by Web Audio before its PCM budget check. Native iOS is bounded. Do not expand browser limits without a streaming/bounded decoder.
- **Entitlements offline:** legitimate verified SDK cache is intentionally usable when network refresh fails. Offline refund visibility follows store/SDK cache. Never-paid unsigned local flags cannot grant ownership; synthetic tests do not establish real refund timing.
- **Local-preview limits:** users can record audible previews with external tools. A client app and a modified/jailbroken binary cannot provide complete DRM. The original free-preview/three-arrangement product rules are preserved.
- **Legacy data:** missing historical paid-tool provenance cannot always be reconstructed. Current effect state is checked at export; new edits/transforms retain markers. Existing projects should be exercised before release.
- **Mobile measurements:** cache/input/export budgets are explicit, but total process memory, jetsam, thermal/battery behavior, native codecs/share destinations and audio routes require physical devices.
- **Scope:** iOS first. Shared changes help Android, but this evidence does not certify its billing, permissions, signing, store declarations or native release.
